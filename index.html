    Known limitations

    • Handles only synthetic, non-clinical weekly at-home support planning for two children in the embedded 18–24-month and 36–48-month age bands, using the bundled activity catalog and policies.
    • The interface, policy text, input interpretation, and generated plans are English-only; multilingual behavior has not been evaluated.
    • The console processes one selected case at a time. Run All is sequential, and the prototype does not monitor households or manage multiple active plans as a live workflow.
    • Inputs must match the embedded case, household, questionnaire, check-in, and policy record formats. Differently structured records are outside the tested scope, and missing critical facts pause planning.
    • A user-supplied OpenAI API key and browser internet access are required, and each run makes two sequential model calls. The reviewer is model-based and can still miss issues; state is browser-local, and the prototype cannot contact professionals, emergency services, caregivers, or other external systems.
